# Parineeta Jain — Portfolio (v2)

React + Vite + TypeScript. Palette: Navy #14213D · Cream #F4EDE0 · Coral #FF6B5B. Three modes: dark, light, dawn.

```bash
npm install
npm run dev      # local dev
npm run build    # outputs dist/
```

Deploy on Vercel: import this repo — framework preset "Vite", build `npm run build`, output `dist`.
